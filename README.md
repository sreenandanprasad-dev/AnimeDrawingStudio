
# AnimeDrawingStudio

An Android anime illustration and pose-reference app.

## Planned features

- Touch-friendly drawing canvas
- Pen, pencil, brush and eraser
- Adjustable brush size and colours
- Undo and redo
- Multiple drawing layers
- PNG export
- 3D anime male, female and teenager pose-reference models
- Adjustable 3D model rotation and poses
- Android 13 support

## Build

The APK will be built using GitHub Actions.
